# Музична школа «Мрія»

Навчальний вебпроєкт для практики студентки Вікторії. Сайт допомагає познайомитися з музичними напрямами, викладачами та записатися на пробний урок.

## Можливості

- Головна сторінка з описом школи та популярними напрямами.
- Каталог курсів із фільтрами за категоріями.
- Сторінки деталей курсу з викладачем, тривалістю, ціною та розкладом.
- Форма онлайн-запису з клієнтською та серверною валідацією.
- Контакти та адаптивна навігація.
- REST API на Node.js/Express.

## Технології

React, Vite, React Router, Node.js, Express, CSS.

## Запуск локально

Потрібен Node.js 20 або новіший.

```bash
npm install
npm run dev
```

Vite відкриє адресу, яку покаже в терміналі (типово `http://localhost:5173`); API працює на `http://localhost:4000`.

```bash
npm test
npm run build
```

Для запуску API окремо використовуйте `npm start`. Для перегляду production-збірки після `npm run build` виконайте `npm run preview`.

## API

| Метод | Шлях | Призначення |
|---|---|---|
| `GET` | `/api/health` | Перевірка доступності API |
| `GET` | `/api/courses` | Список курсів |
| `GET` | `/api/courses/:id` | Деталі курсу |
| `POST` | `/api/trial-lessons` | Перевірка й реєстрація заявки |

Тіло запиту на запис: `name`, `email`, `phone`, `courseId`, `preferredDate`, необов’язковий `note`. Заявки зберігаються в пам’яті процесу як демонстраційний приклад і зникають після перезапуску; перед реальним використанням потрібне постійне сховище та налаштування захисту персональних даних.

## Скріншоти

Для звіту перевірено відображення п’яти маршрутів при ширинах 360, 768 і 1280 px без горизонтального переповнення; також у браузері перевірено фільтр каталогу, помилки порожньої форми, успішний тестовий запис і мобільну навігацію. Додайте збережені скриншоти головної, каталогу, сторінки курсу та форми до `docs/screenshots/`. Для звіту також потрібні скриншоти Lighthouse mobile і сторінок макетів у Figma. Ці докази потрібно додати після створення дизайну й розгортання; результати Lighthouse не заявляються без вимірювання.

## Деплой

У проєкті є `vercel.json` та функції API у `api/`. Локальна гілка `main` уже ініціалізована; станом на цей опис у ній один первинний коміт `0f7c928`. Публічного remote поки немає, тому вимоги про публічний GitHub-репозиторій і щонайменше 30 змістовних комітів ще не виконані. Не створюйте штучну історію заради лічильника — коміти мають відповідати реальним окремим змінам.

Щоб опублікувати код:

1. У GitHub створіть порожній публічний репозиторій `mriya-music-school` для акаунта `C0mplexVlad`. Не додавайте README, `.gitignore` чи license, оскільки вони вже є локально.
2. У терміналі в папці проєкту виконайте команди з URL, показаним GitHub:

   ```bash
   git remote add origin https://github.com/C0mplexVlad/mriya-music-school.git
   git push -u origin main
   ```

3. Імпортуйте репозиторій у Vercel, оберіть production-гілку `main` і перевірте успішність першого deploy.
4. Додайте URL опублікованого сайту сюди: **Демо: додати посилання після deploy**.

Вхід виконуйте самостійно у браузері або через Git Credential Manager; не вставляйте паролі чи токени у вихідний код або чат.
